smart_toybot hosting

make a discord bot with no code, or upload your own (node.js or python), and host it on the oeper.dev server. pick a starting point, switch on what you want, paste your bot token and press start — it restarts itself if it crashes and comes back after a server restart. hosting is paid for with oeper.dev credits, only while a bot is running.

put your bot token in the env tab (e.g. DISCORD_TOKEN) and read it from the environment in your code — never paste it into a file. bots only see their own variables, never the server's. a bot's entry file is found automatically: package.json start script, then index.js / bot.js / main.js, then main.py / bot.py. zip uploads are extracted for you; press install to fetch package.json / requirements.txt dependencies. node bots are capped at their size's memory; a bot that needs more should be moved to a bigger size.
