codeepicenter for developers

Ship updates through Epicenter in three steps. It takes about five minutes, and after that every release is one command.

rule

The rule: every downloadable app (APK, installer, disk image, package…) must give Epicenter an update manifest, a small JSON file at a link that never changes. Submissions without a readable manifest are refused. Web apps and store links (App Store, TestFlight) update themselves and are exempt.

1Host an update.json

Put this next to your download, at an address you keep the same for every release (a GitHub release asset called update.json on a rolling tag works well). The helper in step 3 writes it for you.

update.json
  • versionCode is required for Android (the number in your build.gradle). Elsewhere versionName is enough.
  • sha256 is optional but advised: the Epicenter app refuses a download that does not match it. If you leave it out, nothing stale is checked.
  • Keep the download link stable too (for GitHub: https://github.com/you/app/releases/latest/download/App.apk) so only the manifest changes.

2Submit the app once

On oeper.dev/epicenter press submit an app and fill in the downloads. Every file has a manifest box: paste the update.json link there. An owner approves new apps; after that, new versions appear by themselves: Epicenter reads your manifest every 6 hours (and whenever someone opens the store).

3Release with one command

The helper measures your build, writes update.json and can tell Epicenter right away. Get it at epicenter-release.mjs (Node 18+, no installs).

terminal

To skip the 6-hour wait, make a publish key (store page → my apps → publish keys) and add --publish com.example.app --key epk_…. A key can only touch apps you own.

4Make your app check for updates

One call answers “is there a newer version of me?” and works from any language:

HTTP

Copy EpicenterUpdate.kt into your project (no libraries) and call it from your launch screen. open hands over to the Epicenter app for a one-tap update, or opens the store page if it is not installed.

update-check.js
update_check.py

It is one HTTPS GET that returns JSON (see above). Compare versionCode (or version) with your own and show your usual “update available” message with a button that opens deeplink or page. Never install silently.

5Automate it (GitHub Actions)

Add your publish key as a repository secret named EPICENTER_KEY. This builds, publishes the release files and tells Epicenter:

.github/workflows/release.yml

CallWhat it does
