search API

oeper.dev's own search, as a free public API. One GET request, JSON back, no key. It searches pages, tools, articles, downloads, the docs, posts, videos, people and Epicenter apps. Nothing private is indexed (no e-mail addresses, chats or shared conversations).

try it

press search

search

GET https://oeper-ai.oeper.workers.dev/api/search?q=chess&type=page&limit=10
parametermeaning
qwhat to look for (required, up to 120 characters). Several words must (mostly) all match. Small typos still find things.
typeonly one kind: page, doc, post, video, user, app, article, download. Leave out for everything.
limitresults per page, 1 to 50 (default 20).
offsetskip this many results (for the next page).

url is a path on https://oeper.dev. counts is how many matches each type has (for filter chips), total how many match in the chosen type, and didYouMean is a corrected query when almost nothing matched. People results have a photo; posts and videos have by and at (milliseconds).

suggest

GET https://oeper-ai.oeper.workers.dev/api/search/suggest?q=vid

Up to 8 compact results (type, title, url, icon) for search-as-you-type. With an empty q it returns the site's quick links. This is what the search box in the top bar uses.

stats

GET https://oeper-ai.oeper.workers.dev/api/search/stats

How many things are indexed, by type.

rules

  • Free to use from any website or program (CORS is open for GET). Please keep it under about 2 requests a second; over 120 a minute from one address answers 429.
  • Answers are cached for 30 seconds. New posts show up within a couple of minutes.
  • Be kind: link back to oeper.dev, do not copy the index.

examples

curl "https://oeper-ai.oeper.workers.dev/api/search?q=discord+bot&limit=3"

const r = await fetch('https://oeper-ai.oeper.workers.dev/api/search?q=' + encodeURIComponent('piano'));
const { results } = await r.json();
for (const x of results) console.log(x.type, x.title, 'https://oeper.dev' + x.url);

import requests
r = requests.get('https://oeper-ai.oeper.workers.dev/api/search', params={'q': 'qr code', 'type': 'page'})
print([x['title'] for x in r.json()['results']])
